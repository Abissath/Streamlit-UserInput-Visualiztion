    "# 📊 MABITECH Streamlit Demo App\n",
    "\n",
    "A simple, interactive data visualization app built with [Streamlit](https://streamlit.io/), designed for teaching purposes. It demonstrates core Streamlit features including user inputs, data generation, and multiple chart types.\n",
    "\n",
    "---\n",
    "\n",
    "## 🚀 Features\n",
    "\n",
    "- **User Inputs** — Text input, slider, selectbox, and checkbox widgets\n",
    "- **Data Generation** — Randomly generated sales and customer data using NumPy and Pandas\n",
    "- **Interactive Visualizations** — Line chart, bar chart, and scatter plot via Matplotlib\n",
    "- **Built-in Streamlit Charts** — Area chart using Streamlit's native charting\n",
    "\n",
    "---\n",
    "\n",
    "## 🛠️ Tech Stack\n",
    "\n",
    "| Library | Purpose |\n",
    "|---|---|\n",
    "| [Streamlit](https://streamlit.io/) | Web app framework |\n",
    "| [Pandas](https://pandas.pydata.org/) | Data manipulation |\n",
    "| [NumPy](https://numpy.org/) | Random data generation |\n",
    "| [Matplotlib](https://matplotlib.org/) | Custom chart rendering |\n",
    "\n",
    "---\n",
    "\n",

    "   ```\n",
